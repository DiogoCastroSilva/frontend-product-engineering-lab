Accessibility and quality gate

  • Target WCAG 2.2 AA; verify rather than assuming conformance.
  • Check normal-text contrast at 4.5:1 and large text/meaningful non-text UI at 3:1, considering applicable exceptions.
  • Every control has an accessible name; errors are in text and associated with fields.
  • Keyboard operation and visible, unobscured focus; aim for 44×44 CSS px targets where practical.
  • Support zoom, narrow screens, orientation, and reduced motion.
  • Combine automated checks with manual keyboard and screen-reader testing.
This is a design handoff, not proof of implemented behavior or WCAG conformance. Verify actual token pairs, rendered components, stories, and user flows.
